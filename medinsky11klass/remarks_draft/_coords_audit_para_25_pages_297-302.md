# Отчёт корректора координат — §25, стр. 297–302

Продолжение прогона по §25 (стр. 293–302): стр. 293–296 сделаны предыдущим
прогоном и не трогались. Этот прогон — стр. 297–302, 6 страниц, 27 аннотаций.

Метод: координаты бралось только с картинки (`images_with_grid/page_NNN.png`,
кроп+зум через PIL) и построчной разметки текста (`text/page_{NNN+1}.json`,
только текст и порядок строк, поле `bbox` не использовалось). Для страниц
без иллюстраций дополнительно строилась «линейка» через программное
детектирование горизонтальных полос текста (порог по яркости, столбец без
фотографий) — она во всех случаях совпала с визуальной проверкой по сетке
в пределах 1–3 px.

## Сквозной сдвиг страницы

Явного одинакового сдвига (когда все Δy на странице близки) не обнаружено:
на каждой странице разности «старый y − новый y» разбросаны в диапазоне
150–600 px без общего паттерна — похоже, что исходные координаты ставились
не по систематической ошибке смещения, а по правилу «точка где-то в середине
строки-якоря» индивидуально для каждой аннотации.

## Якорь не определён однозначно

Не встретилось ни одной аннотации, где якорь не определяется — во всех 27
случаях в тексте замечания есть прямая цитата или однозначный предмет
(вопрос №N, пункт списка, заголовок раздела), позволяющий найти начало
соответствующего предложения/абзаца.

Особый случай — **ann-p301-1** (стр. 301): цитата Ельцина начинается на
предыдущей странице (300) и на стр. 301 присутствует только её продолжение
(«в новое тысячелетие с новыми политиками...»). Настоящее начало предложения
физически не на этой странице, поэтому маркер поставлен на первое слово,
видимое на стр. 301 (самый верх страницы, «в»). Это лучшее доступное решение
в рамках рабочего диапазона (менять координаты аннотации на стр. 300, где
предложение начинается на самом деле — не входит в диапазон задания и не
относится к этой аннотации, которая физически привязана к стр. 301).

## Разведение соседей (слипание)

Единственный случай, где сработало правило разведения — **ann-p297-3**
(«компромиссная фигура — И. Рыбкин»): дефолтная позиция (первое слово
предложения «Первым председателем...», [180, 770]) оказалась в 54 px от
маркера соседней аннотации ann-p297-5 («Принятие Конституции...», [175, 826])
— короче минимума в 60 px для пары main/comment. Применён первый запасной
ход из свода правил: маркер перенесён на первое слово цитаты «компромиссная»
внутри того же предложения — [410, 803]. Расстояние до соседей после этого
> 90 px везде.

## Замеченные попутно содержательные проблемы (без правок)

- Стр. 297, ann-p297-3: комментарий называет Рыбкина «компромиссной фигурой»
  без пояснения, между кем компромисс — сама заметка отмечает это, правок не
  требует.
- Стр. 301, ann-p301-1: значимо, что вся цитата Ельцина физически разбита
  между стр. 300 и 301 — по смыслу аннотация могла бы быть на стр. 300 (где
  цитата начинается), но id и текст жёстко привязаны к файлу page_301.md;
  координатор может рассмотреть перенос аннотации на предыдущую страницу как
  отдельное решение (не входит в мандат этого прогона — содержание не
  меняется).
- Прочих смысловых проблем не замечено.

## Что осталось сомнительным

- **ann-p302-1** и **ann-p302-3**: замечания относятся к разделу в целом
  («Работаем с источником» — единственный документ параграфа; «Дополнительные
  материалы» — все три фильма не по теме параграфа). Маркер поставлен на
  заголовок раздела как наиболее естественную точку для замечания о разделе
  целиком — это следует из правила «замечание о подразделе целиком → первое
  слово абзаца», но заголовок формально не «абзац», а строка-разделитель;
  альтернатива (например, первая строка текста внутри раздела) тоже
  правдоподобна. Решение сделано в пользу заголовка, так как замечание прямо
  ссылается на название раздела («Работаем с источником», «Дополнительные
  материалы»).
- **ann-p299-3**: вопрос-врезка «В чём схожесть...» напечатан в блоке рядом
  с плакатом (фото занимает правую часть той же серой плашки). Маркер стоит
  на первом слове вопроса у левого края блока — при d=100 (main) диск почти
  касается левого края страницы (левый край диска ≈ x=57), это ожидаемо для
  вопроса, напечатанного близко к полю.
- Рендер-проверки для всех 6 страниц пройдены визуально (см. картинки в
  scratchpad, раздел «Результат» ниже) — маркеры разбросаны по ширине полосы,
  не слипаются, не обрезаны краем, каждый диск накрывает начало своего
  предложения.
